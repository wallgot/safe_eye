# SAFE-EYE

AI 기반 보행안전 현장점검 우선순위 지원 시스템

## 프로젝트 개요

SAFE-EYE는 시민·조사자가 관찰한 보행환경 정보와
성남시 공공데이터를 결합하여 위험요소를 구조화하고,
현장점검 우선순위를 지원하는 AI 기반 의사결정 시스템입니다.

## 핵심 흐름

보행환경 관찰  
→ Risk Evidence  
→ 공공데이터 결합  
→ Risk Engine  
→ 현장점검 우선순위

## 주요 기능

- 보행환경 관찰 등록
- 현장 사진 업로드
- Risk Evidence 생성
- 성남시 공공데이터 연계
- 설명 가능한 Risk Score
- 현장점검 우선순위 제공

## 기술 스택

- Python 3.12
- Streamlit
- Pandas
- Pillow
- OpenAI API
- SQLite
- Git / GitHub
